📌 Project Overview

This project is a simple Stock Portfolio Tracker developed using Python.
The user enters stock names and quantities, and the program calculates the total investment value using predefined stock prices stored in a dictionary.

To build a basic financial tracking system and strengthen understanding of Python fundamentals including dictionaries, loops, and arithmetic operations.
